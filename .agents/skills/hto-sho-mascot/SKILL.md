# Гусь Шо Mascot

Read [references/mascot.md](references/mascot.md) before generating, editing, or approving mascot artwork. Always inspect and provide [assets/goose-sho.png](assets/goose-sho.png) as the canonical image reference when visual tools are used.

## Working Rules

- Use the image-generation/editing workflow for new artwork. Prefer reference-guided editing or generation over recreating the character from text alone.
- Preserve the mascot's identity before changing emotion, pose, clothes, or props.
- Default standalone mascot deliverables to a high-resolution transparent PNG with clean edges and the complete silhouette in frame.
- Express emotion mainly through eyelids, brows, pupils, beak angle, neck posture, wing gesture, and body lean. Keep the goose recognizable even at thumbnail size.
- Retain the warm editorial cartoon rendering, black outline, cream-white feathers, orange beak and feet, small blush, and signature head tuft.
- Use the phone, blue plaid shopping bag, groceries, list, chat bubbles, or basket only when the scenario calls for them. Props must support the requested story rather than conceal the mascot.
- Do not convert Гусь Шо into a duck, realistic bird, 3D mascot, generic sticker character, or a different illustration style unless the user explicitly requests a deliberate reinterpretation.
- If the user requests several emotions, keep proportions, line work, lighting, and camera angle consistent across the set.
