# Хто Шо?

`Хто Шо?` допомагає невеликим компаніям вирішити, яку їжу купити для спільної події: пікніка, вечірки, виїзду чи домашньої зустрічі.

Зазвичай таке планування живе в Telegram, Viber або іншому груповому чаті. Учасники впереміш пишуть, хто прийде, що любить, чого не їсть, на що має алергію і що принесе сам. Замість перенесення цієї переписки у форми організатор додає до `Хто Шо?` звичайний текст або скриншоти.

## Як має працювати продукт

1. Організатор створює подію і за потреби додає кількість людей, бюджет та короткий контекст.
2. Додає текст, скриншоти або кілька послідовних фрагментів переписки.
3. AI-harness на OpenAI або Ollama об'єднує джерела в один актуальний стан: учасники, відвідування, вподобання, дієтичні обмеження, алергії, напої та домовленості про те, хто що принесе.
4. Сервіс показує висновки, невирішені питання і список покупок із розумними кількостями. Користувач переглядає результат перед синхронізацією.
5. Через OAuth-авторизований Silpo MCP сервіс добирає відповідні товари й створює або оновлює кошик у профілі Сільпо. Кошик залишається чернеткою для перевірки; сервіс не оформлює і не оплачує замовлення.

```text
текст і скриншоти → актуальний стан події → список покупок → кошик Сільпо
```

## Основні правила продукту

- Переписка є неструктурованим джерелом, а не готовим замовленням. Треба відділяти підтверджені факти від припущень і питань.
- Новіша явна домовленість замінює старішу суперечливу домовленість.
- Алергії та дієтичні обмеження є жорсткими обмеженнями. Невизначеність треба показати користувачу, а не вгадувати.
- Те, що учасник принесе сам, не слід вдруге додавати до загального кошика.
- Нові джерела можуть змінити висновки. Після цього попередній список і синхронізований кошик вважаються застарілими, доки їх не перераховано.
- AI пропонує план, а людина контролює зовнішню дію з кошиком.

Детальний контракт для LLM та інтеграції з MCP зберігається у repo-local skill [`hto-sho-product-logic`](.agents/skills/hto-sho-product-logic/SKILL.md).

## Технології

- Laravel 13
- MySQL
- Tailwind CSS 4
- Vite 8
- Laravel Boost
- AI-harness із сумісними провайдерами OpenAI та Ollama
- Silpo MCP з OAuth-авторизацією

## Локальний запуск

```bash
composer install
npm ci
php artisan migrate
npm run build
```

Локальна адреса: [https://hto-sho.local](https://hto-sho.local).
