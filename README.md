# Хто Шо? 🪿

**Гусь, який розгрібає груповий чат, збирає зрозумілий список і готує кошик Сільпо до вашої перевірки.**

[Запустити Гуся на hto-sho.app](https://hto-sho.app/)

Пікнік, вечірка, виїзд чи домашня зустріч зазвичай починаються однаково: хтось буде, хтось передумав, Оля не їсть гостре, Тарас бере вугілля, а повідомлення про алергію вже втекло на три екрани вгору. `Хто Шо?` читає текст і скриншоти цієї пригоди, складає домовленості докупи й залишає людині останнє слово.

```text
чат і скриншоти → що насправді вирішили → список покупок → перевірений кошик Сільпо
```

## Що вже вміє Гусь

1. **Впускає через Сільпо.** Авторизація працює через OAuth без окремого пароля у `Хто Шо?`.
2. **Створює подію без анкети на сорок полів.** Достатньо назви й нормального людського опису; кількість гостей, бюджет та інший контекст можна додати або виправити пізніше.
3. **Їсть текст і скриншоти.** Джерела можна додавати хвилями, переглядати, тимчасово не враховувати та повторно обробляти після помилки.
4. **Розкладає чат по поличках.** Гусь збирає актуальних учасників, відвідування, вподобання, алергії, обмеження, напої, бюджет і домовленості про те, хто що принесе.
5. **Не маскує здогадки під факти.** Суперечності й важливі прогалини стають питаннями, на які організатор може відповісти прямо у події.
6. **Будує список покупок.** Кількості рахуються з поточного контексту, а речі, які гості вже пообіцяли принести, не купуються вдруге. Список можна скоригувати людською мовою.
7. **Звіряє маршрут Сільпо.** Перед пошуком товарів користувач бачить адресу, магазин, спосіб отримання, відправлення та доступний час. Маршрут можна описати фразою або вибрати вручну; прострочений слот змінюється лише після окремого підтвердження.
8. **Шукає реальні товари, а не фантазує етикетки.** Є режим із підстраховкою, де Гусь питає лише після вичерпаного пошуку, і повний автопілот із помітними застереженнями для фінальної перевірки.
9. **Збирає тимчасовий кошик наживо.** Видно прогрес, пояснення вибору, заміни, кількості, ціни й питання до паковання. Велике вікно можна тільки згорнути: компактний Гусь продовжує працювати й повертає до того самого місця.
10. **Чекає на людське “так”.** Лише після фінального перегляду сервіс повторно звіряє маршрут і одним контрольованим оновленням додає погоджені позиції до поточного кошика, не чіпаючи сторонні товари.
11. **Лишає сліди пригоди.** Журнал показує, що Гусь перевіряв, що вирішив, де попросив допомоги й де перечепився.

## Де людина тримає кермо

- Алергії, дієтичні обмеження, вид м’яса, алкоголь та інші жорсткі заборони не можна “оптимізувати” красивою заміною.
- Якщо склад або алергени не підтверджені даними товару, позиція отримує помітне попередження перевірити паковання.
- Новий текст, скриншот або виправлення роблять старі висновки, список і кошик неактуальними до нового розрахунку.
- Поточні товари користувача в кошику Сільпо зберігаються. Гусь не очищає кошик і не повторює сліпо сумнівний запис.
- `Хто Шо?` не оформлює, не оплачує і не завершує замовлення. Остання лапа на кнопці завжди людська.

Докладний контракт продукту й інтеграції живе в repo-local skill [`hto-sho-product-logic`](.agents/skills/hto-sho-product-logic/SKILL.md).

## Під капотом

- PHP 8.4 та Laravel 13
- MySQL і database queues
- Tailwind CSS 4 та Vite 8
- PHPUnit 12, Laravel Pint і Laravel Boost
- сумісні AI-провайдери OpenAI та Ollama
- OAuth-авторизований Silpo MCP для профілю, маршрутів, каталогу й кошика

Гусь зберігає походження джерел, прив’язує похідні результати до актуального стану події та відкидає запізнілі відповіді. Зовнішні повтори мають бути ідемпотентними, а доступ до подій, джерел, журналу й кошика обмежений власником.

## Локальний запуск

```bash
composer setup
```

Після цього налаштуйте AI-провайдера та Silpo MCP у `.env`, підключіть локальний вебсервер і в окремих терміналах запустіть чергу та збірку:

```bash
# термінал 1
php artisan queue:work

# термінал 2
composer run dev
```

Корисні перевірки перед тим, як випускати Гуся з двору:

```bash
vendor/bin/pint --format agent
php artisan test --compact
npm run build
```
