# Хто Шо? Brandbook

Read [references/brandbook.md](references/brandbook.md) before making or reviewing a brand-facing artifact. Use [assets/brandbook.png](assets/brandbook.png) when visual comparison or a design reference is useful.

## Working Rules

- Default customer-facing language to Ukrainian.
- Preserve the exact core palette, Manrope-led typography, hand-drawn accents, warm paper background, and friendly organized-chaos character.
- Keep the brand practical and human. Explain the outcome before the technology; avoid generic AI/SaaS language.
- Use colloquial humor deliberately. Strong phrases such as `срач у чаті` belong in playful campaigns, not automatically in trust, legal, or transactional UI.
- Maintain accessible contrast and legible body text even when using playful shapes or handwritten accents.
- Treat the canonical board as the source of truth. If an explicit user direction departs from it, follow the request and state the departure instead of silently redefining the brand.
- When Гусь Шо appears or needs a new pose or emotion, also use `$hto-sho-mascot`.
